# Architecture

## 1. Data model (`src/fluent/travel/travel-request.now.ts`)

Table `x_2313668_pumkin_s_travel_request` (display field: `title`).

| Group | Fields |
|-------|--------|
| Trip basics | title*, purpose (tour leg, festival, promo appearance, recording session, other), destination_city, departure_date*, return_date* |
| Travel details | transportation (flight, car rental, personal vehicle), flight_class, rental_car_size, mileage_estimate |
| International | international_trip, passport_expiration_date, visa_required |
| Justification | business_justification*, estimated_total_cost |

`*` = mandatory. A `Form` on the default view groups these into sections.

## 2. UI policies (`ui-policies.now.ts`)

- Transportation = Flight shows Flight class and hides Rental car size and Mileage.
- Transportation = Car Rental shows Rental car size and hides the others.
- Transportation = Personal Vehicle shows Mileage estimate.
- International trip shows the passport and visa fields.

## 3. Security (`access.now.ts`)

| Operation | Rule |
|-----------|------|
| read | any authenticated user |
| create | any authenticated user |
| write | creator only (`sys_created_by = current user`); admin override on |

## 4. Navigation (`menu.now.ts`)

Application menu **Tour Travel**, with a **Travel Requests** list module.

## 5. Service Portal (`src/fluent/portal`)

- `portal.now.ts`: portal "Tour Travel", URL suffix `x_2313668_pumkin_s`, OOTB login and 404 pages.
- `pages.now.ts`: pages `…_home`, `…_request`, `…_detail`.
- `widgets/`: `dashboard`, `request-form`, `request-detail`, each with a template, a client script and a server script.
- `pages/tour-travel.css`: shared styling that travels with each page, so the pages also render in Employee Center.

## 6. React UI page (`src/client`, `src/fluent/ui-pages`)

React 19 incident manager (form, list and a service wrapper). It is bundled with `@servicenow/isomorphic-rollup` through `now.dev.mjs` and `now.prebuild.mjs`.

## 7. Demo data (`demo-data.now.ts`)

Sample requests (for example "Querystring - Berlin Festival") use `installMethod: 'demo'`. They are only loaded when demo data is installed.

## 8. Build and deploy flow

1. `now-sdk build` compiles the Fluent metadata and client bundle.
2. `now-sdk install` pushes the app to the instance saved as default in `now-sdk auth`.
3. `src/fluent/generated/keys.ts` is regenerated by the SDK and should be committed.
